# NeonOS
## An OS-like program to run in the web. Made for hackclub stardance.
![Cover Image](https://raw.githubusercontent.com/Cesium72/NeonOS/refs/heads/main/neonos.png)
## Live Preview
The whole thing is static, so it is all visible on [github pages](https://cesium72.github.io/NeonOS)
## Features
- Standard OS Stuff (windows, dragging, top bar, etc.)
- Primitive Notes App
- A fun media app
